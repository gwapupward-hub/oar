# OAR v0.1.1-rc.2 (pre-release)

This candidate adds guided registration for apps that are already live. The protocol surface is unchanged from `v0.1.1-rc.1`:

- manifest format `0.1`;
- AppRecord layout `1`;
- SAS link schemas version `2`.

The program binary is the one deployed on devnet; the table below confirms it byte for byte.

**Status: devnet deployed and verified. Mainnet: NO-GO.**

## What is new

- **`oar claim`** takes an existing app from files to verified links:
  - `prepare` derives the App ID and writes the manifest, the domain proof and the repository proof;
  - `check` verifies hosting and every proof, and signs nothing;
  - `register` refuses until the hosted manifest matches the one being committed;
  - `link-program` signs as the upgrade authority, or with `--squads` prints an unsigned proposal for a Squads vault.

  Every transaction is summarized in plain sentences first and is signed only with `--yes`. The guide for teams is `docs/REGISTERING.md`.
- **`@open-app-registry/sdk/register`** is a new entry point with no Node APIs, for browser wallets. It exports:
  - `nextAppNonce`;
  - `getProgramLinkInstructions`, which writes the canonical `oar` backlink as readable, uncompressed JSON;
  - `describeRegistration` and `describeProgramLink`;
  - `exportUnsignedTransaction`;
  - `assertRegistrationInstructions`, which refuses anything outside the OAR, Program Metadata, System and Compute Budget programs.

  The main entry point adds `checkManifestHosting`.
- **Spec:** `https://<listed domain>/.well-known/oar-manifest.json` is a recommended manifest location, next to `ar://` and `ipfs://`.

## Not in this candidate (mainnet gates)

- An independent security review. The scope, now including the registration builders, is in `docs/SECURITY-REVIEW-SCOPE.md`.
- Squads multisig upgrade governance, rehearsed on devnet. Devnet upgrades are held by a single key (OAR-IR-05).
- Operations: a dedicated RPC, monitoring and a rollback rehearsal.
- A production SAS issuer. The default trust list is empty.
- A devnet rehearsal of `oar claim` with a wallet-held and a Squads-held program, run by an operator.
