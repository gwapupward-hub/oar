# Security policy

Report vulnerabilities privately through GitHub Security Advisories for this repository ("Report a vulnerability" under the Security tab). Do not open public issues for security problems.

Scope: the `oar-registry` program, the SDK's verification logic (`packages/sdk/src/links.ts`, `attestations.ts`, `resolve.ts`, `manifest.ts`) and the JSON Schemas.

The reference program is pre-audit and not deployed to mainnet.
