# OAR Brand Assets

Canonical repository subset of **OAR Brand System v1.0**.

**Tagline:** Open by default. Verifiable by design.

This directory intentionally contains the reusable assets needed by contributors and product surfaces, not every export in the full distribution kit.

## Use

- `logos/OAR_primary_dark.svg` — primary lockup for dark surfaces
- `logos/OAR_primary_light.svg` — primary lockup for light surfaces
- `logos/OAR_icon_gradient.svg` — canonical Registry Ring mark
- `logos/oar_developer_*.svg` — developer-facing CLI/SDK treatment
- `icons/` — app icon and favicon exports
- `tokens/` — design tokens and typography guidance
- `copy/` — canonical copy and evidence-state terminology

See [`../BRANDING.md`](../BRANDING.md) for mandatory usage rules.

The complete OAR Brand Kit v1.0 (PDF guide, social assets, reference boards, and additional raster exports) is distributed separately from the source repository.
