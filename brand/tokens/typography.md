# OAR Typography

- **Primary UI / brand:** Inter
- **Developer / CLI:** Geist Mono preferred; IBM Plex Mono acceptable fallback.
- **Fallback stack:** Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
- **Mono fallback stack:** "Geist Mono", "IBM Plex Mono", ui-monospace, SFMono-Regular, Menlo, monospace

Font files are intentionally not redistributed in this brand kit.
