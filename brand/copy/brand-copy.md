# OAR Brand Copy

## Name
**OAR — Open App Registry**

## Primary tagline
**Open by default. Verifiable by design.**

## One-line description
OAR is an open registry for publishing, discovering, and verifying application identity across the Solana ecosystem.

## Technical description
Open App Registry is an open application identity layer connecting apps, domains, programs, metadata, source information, builds, and attestations through a common registry.

## Core pillars
Open · Verifiable · Composable · Neutral · Developer-first

## Product family
OAR Registry · OAR Protocol · OAR SDK · OAR CLI · OAR Explorer · OAR Schemas · OAR Docs

## Messaging guardrail
OAR surfaces evidence. It should not imply that a registry listing is a security guarantee or that OAR centrally certifies an app as safe.
