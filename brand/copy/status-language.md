# OAR Status Language

Use evidence-specific states instead of a blanket **Verified App** badge.

## Approved examples
- Published
- Domain linked
- Program linked
- Source available
- Build reproduced
- Attested
- Unknown
- Disputed / invalid

## Rule
Statuses describe the evidence OAR can substantiate. They do not imply general safety, endorsement, quality, or official Solana approval.
